## 📋 Descripción

Aplicación de escritorio para consultar el **Archivo de Exoplanetas de la NASA** con una interfaz gráfica intuitiva. Permite buscar, filtrar y ordenar datos de exoplanetas descubiertos.

## ✨ Características

- 🔍 **Búsqueda avanzada** por año, método, estrella anfitriona e instalación
- 📊 **Visualización en tabla** con los resultados
- ⬆️⬇️ **Ordenamiento** ascendente/descendente por cualquier columna
- 🔗 **Enlaces directos** a la página oficial de la NASA
- 🎯 **Interfaz moderna** con Tkinter
- ⚡ **Carga eficiente** de datos con Pandas

## 🛠️ Tecnologías

- **Python 3.8+** - Lenguaje principal
- **Pandas** - Procesamiento de datos
- **Tkinter** - Interfaz gráfica (incluido en Python)
- **NumPy** - Operaciones numéricas eficientes
